# 音MAD Auto Maker

Python + Flet で作る音MAD自動制作ソフトのプロトタイプです。

## 主な機能
- WAV/MP3素材の読み込み
- 無音区間を利用した自動チョップ
- BPMに合わせたグリッド生成
- MIDI（SMF）読み込み → ノート列化
- 素材をMIDIの音階に合わせてピッチシフトして配置
- BGMとの簡易ミックス（BGM音量の調整に対応）
- 音量・パンの自動調整
- WAV / MP3 書き出し
- Flet GUI
- 動画テンプレート用のタイムラインJSON出力
- 複数素材・MIDIトラック別の素材割り当てと音量設定
- 画像/動画の登録と自動割り当て、FFmpegによる音声付きMP4の自動生成
- MIDIトラックごとの単体音声を生成して試聴（トラック別試聴）
- ノートを持たないトラックの自動除外（テンポトラックなどを割り当て一覧から除外）
- 素材読み込み時の基準音（高さ）と明るさの自動判定
- シンセ化／そのまま再生の自動判定（音程感と減衰から判別）
- 解析結果を使ったトラックへの素材の自動割り当てと音量バランスの自動調整
- 素材ごとの基準音、切り出し範囲、シンセ化／そのまま再生
- CLI実行とGUIプロジェクト保存
- 素材解析・ノート描画・動画エンコードの並列実行（`YTPMV_WORKERS` / `YTPMV_VIDEO_WORKERS` で調整可能）

## 必要環境
- Python 3.14+
- FFmpeg（MP3入出力に必要）
- MIDI解析用に `mido`
- 音声処理用に `pydub`
- GUI用に `flet`

## 起動
```bash
pip install -r requirements.txt
python main.py
```

起動時にプロジェクト直下へ `materials/`（素材用）と `outputs/`（成果物用）が自動作成されます。CLI・GUIとも、出力先を指定しない場合は `outputs/` を使い、生成物名には `YYYYMMDD_HHMMSS_mmm` 形式のタイムスタンプが付きます。外部にある素材ファイルは移動せず、そのまま読み込みます。

## CLI

素材を複数指定して生成できます。

```bash
uv run python cli.py -m vocal.wav -m effect.wav --midi melody.mid --bgm bgm.wav --output-dir out
```

GUIで保存した `otomad_project.json` を使う場合：

```bash
uv run python cli.py --project otomad_project.json
```

特定のMIDIトラック単体だけを書き出す場合（0始まりのトラック番号）：

```bash
uv run python cli.py -m vocal.wav --midi melody.mid --solo-track 0 --output-dir out
```

`out/track_1.wav` のように、トラック番号付きのWAVが生成されます（BGMは合成されません）。

`--base-note` を省略すると、素材の基準音は読み込み時に自動判定されます。再生モード（シンセ化／そのまま）も自動判定され、結果と理由が表示されます。プロジェクトJSONにトラック割り当てが無い場合は、下記の自動割り当てと音量バランス調整も適用されます。

```bash
uv run python cli.py -m vocal.wav -m effect.wav --midi melody.mid --output-dir out
```

画像/動画を登録して、音声付きMP4まで書き出す場合：

```bash
uv run python cli.py -m vocal.wav --midi melody.mid \
  --video vocal.png --video effect.mp4 \
  --render-video --video-size 1280x720 --fps 30 --output-dir out
```

- `--video` は複数指定でき、音声素材の順に割り当てられます（ファイル名が素材名に含まれる映像があれば優先）
- `--gap-mode hold`（既定）はノート間の無音区間で直前の映像を続けて表示、`black` は黒画面で埋めます
- 出力: `otomad_result.wav` / `otomad_result.mp3` / `video_timeline.json` / `otomad_result.mp4`

音声素材・MIDI・生成物は `.gitignore` 対象です。公開前に個人情報や素材の権利関係を確認してください。

FFmpeg が PATH にない場合は、FFmpeg をインストールして PATH に追加してください。

## 並列処理

次の処理は複数のワーカースレッド／プロセスで並列実行されます（結果は逐次実行時と同じになります）。

- 素材の読み込み（FFmpegでのデコード）と基準音・再生モードの解析
- ノートごとのピッチシフト・ゲイン・パン（`make_song`）
- 動画の区間ごとのFFmpegエンコード（`render_video`）

並列数は GUI の `並列数` / `動画並列数` 欄、または環境変数で変更できます。`1` を指定すると従来どおり逐次実行になります。

- GUI: `並列数`（音声）と `動画並列数`（動画）を入力して生成ボタンを押すと、次の生成から反映されます（空欄で自動）。値は `プロジェクト保存` したJSONに含まれ、読み込み時に復元されます。
- 環境変数: GUIを起動する前に設定すると、その値が欄の初期値になります。

| 環境変数 | 対象 | 既定値 |
| --- | --- | --- |
| `YTPMV_WORKERS` | 音声の読み込み・解析・ノート描画 | CPUコア数（読み込み・解析は最大4） |
| `YTPMV_VIDEO_WORKERS` | 動画セグメントのエンコード | CPUコア数の半分（最大8） |

```bash
YTPMV_WORKERS=4 YTPMV_VIDEO_WORKERS=4 uv run python cli.py --project otomad_project.json
YTPMV_WORKERS=1 uv run python cli.py --project otomad_project.json   # 逐次実行（比較・検証用）
```

## BGM音量
GUIの `BGM音量dB` 欄、またはCLIの `--bgm-volume` で調整できます。値は BGM の基準音量（-24dBFS に正規化）に対する相対ゲイン(dB)で、`0` が既定、プラスで大きく、マイナスで小さくなります。

```bash
uv run python cli.py -m vocal.wav --midi melody.mid --bgm bgm.wav --bgm-volume -6 --output-dir out
```

設定値はプロジェクトJSONの `bgm_volume` に保存されます。

## 自動解析・自動割り当て・自動バランス
素材を追加すると、読み込み時に次の値を自動判定します（`素材一覧` の「自動判定」ボタンで再計算もできます）。

- **基準音（高さ）**: 65〜1200Hz 帯のスペクトルピークからMIDIノート番号を推定します。
- **明るさ**: スペクトル重心(Hz)。倍音の多い明るい音ほど大きくなります。
- **再生モード（シンセ化 / そのまま）**: 次の指標から判別します。
  - 倍音成分比（基音の倍音に含まれるエネルギー）とスペクトル平坦度 → 音程感の有無
  - アタック時間・ピーク比・持続比率 → 打楽器/効果音らしい一発音かどうか
  - 判定: 音程感があり持続する → **シンセ化**（ピッチを変えて演奏）、アタックが鋭く減衰が速い → **そのまま**（原音のまま鳴らす）
  - 判定理由（例: `音程感があり持続する（倍音成分 88% / 平坦度 0.00 / 持続 100%）`）はログに表示されます

「素材一覧」の `再生` は **自動判定 / シンセ化 / そのまま** から選べます。`自動判定` の場合はラベルに現在の判定結果（例: `再生（自動: シンセ化）`）が表示され、生成時に解析結果が使われます。手動で `シンセ化` / `そのまま` を選ぶと自動判定より優先されます。

MIDIを読み込むか素材を追加すると、「自動割り当て＋バランス」が自動で実行されます（ボタンから手動実行も可能）。

- **自動割り当て**: トラックごとに次の基準で最も自然に鳴る素材を選びます。
  - 素材の基準音とトラックの平均音高の差が小さい（ピッチ変更が少ない）ほど高評価
  - 1オクターブを超えるピッチ変更は大きく減点
  - 素材の明るさとトラックの音域の順位が近いほど高評価
  - 同じ素材の重複使用は軽く減点
  - トラック名に素材名が含まれる場合は、その素材を優先候補にする（ユーザーの指定を尊重）
  - 音数の多いトラック（主旋律）から先に素材を決めます
- **自動バランス**: トラックごとの音量(dB)を自動調整します。
  - 音数が多い（密な）トラックは合計音量が大きくなるため抑える
  - 最も音数が多いトラック（主旋律）は少し持ち上げる
  - 低音は埋もれやすいので少し持ち上げ、高音は抑える

決定内容（割り当て素材・基準音・音量dB）はログに出力されます。手動で調整したい場合は、割り当てのドロップダウンと音量欄を直接編集してください。

## 動画（自動生成）
「＋ 画像/動画を追加」で映像素材（png/jpg/webp/gif/mp4/mov/webm/mkv/avi）を登録し、「映像の割り当て」で**音声素材ごとに表示する映像**を選びます。`🎬 動画を生成 (MP4)` を押すと、次の流れを一括で実行します。

1. 音声（WAV/MP3）を生成
2. `video_timeline.json`（v2）を出力 — 音声と同じノート配置・チョップ・トラック割り当てで、各ノート区間に「映像ファイル／頭出し位置／長さ」を記録
3. FFmpeg で各区間を映像化して連結し、音声と合成して `otomad_result.mp4` を出力

- 動画素材は音声と同じチョップ位置から頭出しするため、映像と音が同期します。画像素材はその区間ずっと表示されます
- ノート間の無音区間は直前の映像の続きで埋めます（映像が短い場合はループ）
- 映像は `動画サイズ`（例: `1280x720`）へ収まるよう拡大縮小＋余白は黒でレターボックスし、`FPS` に合わせて統一します
- `🎬 動画テンプレJSON` は、MP4を書き出さずタイムラインJSONだけを出力します（外部ツール連携用）

映像が未登録・未割り当ての場合は生成せず、ログに理由を表示します。動画生成にはFFmpeg（`ffmpeg` / `ffprobe`）が必要です。

## トラック別試聴
「素材の割り当て」の各行にある「🎧 試聴」ボタンを押すと、そのMIDIトラックだけを割り当て素材・音量でレンダリングし、出力フォルダに `track_<番号>_preview.wav` として書き出してからプレイヤーで開きます。BGMは合成されないため、トラック単体の音作りを確認できます。

プレイヤーはOSの既定アプリ（Windows: 関連付けアプリ / macOS: `open` / Linux: `xdg-open`）を優先し、利用できない環境では `ffplay`（ウィンドウ表示、`space`＝一時停止 / `q`＝終了）→ `paplay` / `aplay` の順にフォールバックします。

ノートを1つも持たないトラック（テンポ情報だけのトラックなど）は、割り当て一覧と自動割り当ての対象から自動的に除外します。MIDIファイル自体は書き換えないため、元のデータはそのまま残ります。除外したトラック番号はログに表示されます。

## MIDIについて
MIDIノートは標準のMIDIノート番号（60=C4）として扱います。
MIDIの各ノートの長さをグリッド長として使い、素材の基準音からの半音差でピッチを変更します。

## 動画タイムラインJSON
`video_timeline.json` は、動画編集ソフトや独自レンダラーからも利用できる素材・開始時刻・長さ・音程をまとめたテンプレートデータです（v2）。各クリップは音声素材のチョップ情報に加えて、表示する映像（`video_source`）と頭出し位置（`video_start_ms`）を持ちます。
